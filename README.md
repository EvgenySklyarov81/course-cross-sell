# Анализ совместных покупок онлайн-курсов на основе истории пользователей

## 🎯 Цель проекта
На основе истории покупок определить учебные курсы, которые наиболее часто покупаются вместе. На основе расчета частоты этих со-покупок сформировать итоговую таблицу для предложения пользователю до двух дополнительных курсов к уже выбранному.
## 📊 Исходные данные
Источник данных: синтетический датасет, полученный в рамках учебного задания.

Для анализа предоставлены следующие файлы:
* **`all_courses.csv`** — полный справочник доступных онлайн-курсов (127 позиций).
* **`purchased_courses.csv`** — исторический массив покупок пользователей (34 172 записи). Содержит поля `user_id` (идентификатор студента) и `resource_id` (идентификатор курса).

*Примечание:* Также в исходных материалах присутствовал файл `popularity_rank.csv` (рейтинг популярности). Он был исключен из обработки, так как методология его расчета неизвестна, а для решения задачи прямого подсчета частоты пар он не требуется.
## ⚠️ Ограничения и допущения исследования
В силу специфики учебного набора данных, при анализе были приняты следующие условия и ограничения:

* **Отсутствие транзакционных корзин:** В исходных файлах нет номеров заказов (чеков) и дат совершения покупок. Из-за этого невозможно оценить, какие курсы приобретались одновременно в одном заказе. Анализ сфокусирован на поиске совместных курсов в рамках профиля пользователя за всё время.
* **Нетипичная структура выборки:** Минимальное количество покупок на одного уникального пользователя равно двум. В реальности большинство клиентов покупают только один курс.
* **Симметричность связей:** Пары курсов рассматриваются как неупорядоченные. Это означает, что пара (Курс А, Курс Б) то же, что и (Курс Б, Курс А).
* **Метод:** Итоговые рекомендации формируются исключительно на основе абсолютной частоты появления пар. В рамках текущего прототипа не используются коэффициенты силы связи, поэтому популярные курсы-хиты будут попадать в пары чаще остальных просто в силу больших объемов их собственных продаж.

## 📈 Ключевые выводы
В ходе анализа истории покупок были получены следующие результаты:
* **Выявленные пары:** Всего в данных обнаружено **3 989 уникальных пар** курсов, встречающихся у пользователей.
* **Фильтрация шума:** Анализ показал, что **44% пар** встречаются всего у 1–2 пользователей. Такие редкие совпадения были отсечены как случайные. После применения фильтра в работе осталось **928 устойчивых пар**.
* **Абсолютный лидер:** Самой частотной со-покупкой оказалась пара курсов с ID **(551, 566)** — её приобрели **797 пользователей**.
* **Итоговая таблица предложений:** Для каждого из 126 курсов сформирован блок сопутствующих рекомендаций (до 2 позиций):
  * **97 курсов (77%)** получили полноценные двойные предложения;
  * **7 курсов (6%)** получили одно предложение;
  * **22 курса (17%)** остались без предложений, так как для них не нашлось пар, прошедших фильтр по частоте.

## 🚀 Что бы я улучшил
1. **Оптимизация:** Замена итератора `.iterrows()` векторизованными операциями Pandas/NumPy. На текущем массиве (928 пар) код работает быстро, но на реальных данных с миллионами транзакций `iterrows` станет узким местом.
2. **Внедрение метрик силы связи:** Расчет метрик **Confidence** (доля покупателей курса А, выбравших курс Б) и **Lift** (коэффициент превышения случайной вероятности покупки). Это позволит отделить реальные логические связи от глобальной популярности отдельных курсов-хитов.
3. **Обработка редких продуктов (Fallback):** Создание логики заполнения пустых блоков для 22 курсов без пар.

### Для пользователей Anaconda / Conda:
1. Скачайте репозиторий проекта локально на свой компьютер или клонируйте его.
2. Откройте терминал Anaconda Prompt (или обычный терминал) и перейдите в корневую папку скачанного проекта.
3. Создайте изолированное виртуальное окружение из конфигурационного файла `environment.yml` с помощью команды:
   ```bash
   conda env create -f environment.yml
   ```
4. Активируйте созданное окружение:
   ```bash
   conda activate course_cross_sell
   ```
5. Запустите среду разработки, которая автоматически откроется в браузере:
   ```bash
   jupyter lab
   ```
### Для пользователей стандартного Python (без Conda):
1. Скачайте репозиторий проекта локально на свой компьютер или клонируйте его.
2. В терминале перейдите в корневую папку скачанного проекта.

   ```bash

   ```
6. Запустите среду разработки, которая автоматически откроется в браузере:
