# Анализ совместных покупок онлайн-курсов на основе истории пользователей

## 🎯 Цель проекта
На основе истории покупок определить учебные курсы, которые наиболее часто покупаются вместе. На основе расчета частоты этих со-покупок сформировать итоговую таблицу для предложения пользователю до двух дополнительных курсов к уже выбранному.
## 📊 Исходные данные
Источник данных: синтетический датасет, полученный в рамках учебного задания.

Для анализа предоставлены следующие файлы:
* **`all_courses.csv`** — полный справочник доступных онлайн-курсов (127 позиций).
* **`purchased_courses.csv`** — исторический массив покупок пользователей (34 172 записи). Содержит поля `user_id` (идентификатор студента) и `resource_id` (идентификатор курса).

*Примечание:* Также в исходных материалах присутствовал файл `popularity_rank.csv` (рейтинг популярности). Он был исключен из обработки, так как методология его расчета неизвестна, а для решения задачи прямого подсчета частоты пар он не требуется.
## ⚠️ Ограничения и допущения исследования
В силу специфики предоставленного учебного массива данных, при анализе были приняты следующие условия и ограничения:

* **Отсутствие транзакционных корзин:** В исходных файлах нет номеров заказов (чеков) и дат совершения покупок. Из-за этого невозможно оценить, какие курсы приобретались одновременно в одном заказе. Анализ сфокусирован на поиске совместных курсов в рамках профиля пользователя за всё время.
* **Нетипичная структура выборки:** Минимальное количество покупок на одного уникального пользователя равно двум. В реальности большинство клиентов покупают только один курс.
* **Симметричность связей:** Пары курсов рассматриваются как неупорядоченные. Это означает, что пара (Курс А, Курс Б) то же, что и (Курс Б, Курс А).
* **Смещение базового метода:** Итоговые рекомендации формируются исключительно на основе абсолютной частоты появления пар. В рамках текущего прототипа не используются коэффициенты силы связи, поэтому популярные курсы-хиты будут попадать в пары чаще остальных просто в силу больших объемов их собственных продаж.
